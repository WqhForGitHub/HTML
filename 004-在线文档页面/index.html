快速开始

用最短的时间把 Aurora UI 跑起来，并了解核心用法。

1. 安装

推荐使用包管理器安装 Aurora UI。你可以在已有的 Vue 3 项目中执行以下命令：

bash 
# 使用 npm
npm install aurora-ui

# 或使用 pnpm
pnpm add aurora-ui
ℹ️
提示 Aurora UI 依赖 Vue 3.2 及以上版本，请先确认项目环境。

2. 基本用法

完成安装后，可以在入口文件中完整引入组件库：

main.js 
import { createApp } from 'vue'
import App from './App.vue'
import AuroraUI from 'aurora-ui'
import 'aurora-ui/dist/style.css'

const app = createApp(App)
app.use(AuroraUI)
app.mount('#app')

引入完成后，即可在任意组件中使用 Aurora UI 提供的组件：

App.vue 
<template>
  <au-button type="primary">点击我</au-button>
</template>

3. 按需引入（推荐）

为减小打包体积，推荐配合 unplugin-vue-components 实现按需自动引入：

💡
建议 在生产环境中始终使用按需引入，可使首屏体积减少 60% 以上。
vite.config.js 
import { defineConfig } from 'vite'
import Components from 'unplugin-vue-components/vite'
import { AuroraResolver } from 'aurora-ui/resolver'

export default defineConfig({
  plugins: [
    Components({
      resolvers: [AuroraResolver()]
    })
  ]
})

4. 组件属性

以 Button 组件为例，常用属性如下：

属性名 说明 类型 默认值
type 按钮类型 primary / success / warning / danger default
size 按钮尺寸 large / default / small default
disabled 是否禁用 boolean false
loading 加载中状态 boolean false
⚠️
注意 当 loading 为 true 时，按钮会自动禁用点击事件，无需重复设置 disabled。
