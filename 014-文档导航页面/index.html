Button 按钮

常用的操作按钮，提供多种类型、尺寸与状态，支持图标与加载态。

介绍

Button 组件用于触发一个即时操作，是界面中最基础的交互元素。CloudUI 的 Button 提供了丰富的样式变体，可以满足绝大多数场景需求。

ℹ️
提示 按钮文案应简洁明了，建议使用动词 + 名词的组合形式，例如"新建文件"、"删除用户"。

按钮类型

支持 primary 、 success 、 danger 、 outline 四种类型，默认为 outline。

<c-button type="primary">主要按钮</c-button> <c-button type="success">成功按钮</c-button> <c-button type="danger">危险按钮</c-button> <c-button type="outline">描边按钮</c-button>

安装与引入

通过 npm 安装 CloudUI：

$ npm install cloudui --save

在项目中完整引入：

import { createApp } from 'vue';
import CloudUI from 'cloudui';
import 'cloudui/dist/index.css';
import App from './App.vue';

const app = createApp(App);
app.use(CloudUI);
app.mount('#app');
✅
最佳实践 推荐使用按需引入的方式，配合 Vite 插件可以显著减少打包体积。

Button 属性

参数 说明 类型 默认值
type 按钮类型 primary / success / danger / outline outline
size 按钮尺寸 large / default / small default
disabled 是否禁用 boolean false
loading 是否加载中 boolean false
icon 图标名称 string -
round 是否圆角 boolean false

Button 事件

事件名 说明 回调参数
click 点击按钮时触发 event: MouseEvent
focus 按钮获得焦点时触发 event: FocusEvent
⚠️
注意 当按钮处于 disabled 或 loading 状态时，click 事件不会被触发。

常见问题

如何自定义按钮颜色？

可以通过 CSS 变量覆盖默认主题色：

:root {
  --cloudui-primary: #8b5cf6;
  --cloudui-primary-hover: #7c3aed;
}

按钮文字过长怎么办？

建议限制按钮宽度并使用 text-overflow: ellipsis 处理溢出文字，保持界面整洁。
