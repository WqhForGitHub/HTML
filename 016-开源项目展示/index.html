README

快速了解 FastJSON 的用法

FastJSON 🚀

高性能 JSON 解析与序列化库，专为现代 JavaScript 应用设计。

基本用法

import { parse, stringify } from 'fastjson';

// 解析 JSON
const data = parse('{"name":"FastJSON","version":"5.2.0"}');
console.log(data.name); // FastJSON

// 序列化对象
const json = stringify({ name: 'FastJSON', stars: 18200 });
console.log(json); // {"name":"FastJSON","stars":18200}

流式解析大文件

对于超大 JSON 文件，使用流式解析器避免内存溢出：

import { createParseStream } from 'fastjson';
import { createReadStream } from 'fs';

const stream = createParseStream();
stream.on('data', (chunk) => {
  console.log('解析到数据块:', chunk);
});

createReadStream('large-file.json').pipe(stream);
💡 流式解析模式下，无论文件多大，内存占用始终保持在 10MB 以下。

安全模式

启用安全模式防御原型链污染：

import { safeParse } from 'fastjson';

// 自动过滤 __proto__ 等危险字段
const data = safeParse('{"__proto__":{"admin":true}}');
console.log(data); // {} - 危险字段已移除
