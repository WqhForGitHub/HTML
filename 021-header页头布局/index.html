语义元素说明： <header>

<header> 元素代表一个区域的引导性内容（introductory content）。

它通常包含：站点标题、Logo、导航菜单、搜索框、介绍性标题等。

一个页面可以有多个 <header> ，但不应嵌套于 <footer> 或 <address> 中。

关于 <header> 元素

<header> 是 HTML5 引入的语义化标签，用于定义文档或区段的页头。它不仅是视觉上的顶部区域，更在语义上向浏览器和搜索引擎表明此处是引导性内容。

<header> <div class ="logo" > ... </div> <nav> 导航菜单 </nav> <form> 搜索框 </form> </header>

典型用法：放置 Logo、主导航 <nav> 、搜索表单、站点标语等。它帮助辅助技术（如屏幕阅读器）快速定位页面的开头部分。

header 的多种用途

<header> 不仅仅用于整个页面的顶部，它也可以用于 <article> 或 <section> 内部，作为该区域内容的标题区。例如一篇博客文章的标题、作者、发布时间就可以包在文章内的 <header> 中。
