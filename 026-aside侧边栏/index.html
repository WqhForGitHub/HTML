语义元素说明： <aside>

<aside> 表示与主内容相关、但又可独立存在的内容，通常表现为侧边栏。

常见内容：相关链接、作者介绍、广告、标签云、热门文章、订阅表单。

关键特征：去掉 <aside> 后，主内容仍应完整可读。它是对主内容的"补充"。

本页右侧的整个侧边栏就是一个 <aside> 。

深入理解 CSS Flexbox 与 Grid 布局

作者：李明  |  发布于 2026-07-08  |  阅读 2,460

CSS 布局是前端开发的核心技能之一。在现代 Web 开发中，Flexbox 和 Grid 是两大主力布局系统，它们各自擅长不同的场景，理解它们的特点与适用场景，能让我们写出更优雅、更高效的布局代码。

一、Flexbox：一维布局之王

Flexbox（弹性盒布局）是一维布局系统，它擅长处理一行或一列中的元素排列。无论是水平居中、等宽分布、还是自适应分配空间，Flexbox 都能轻松应对。它的核心思想是让容器有能力调整子元素的宽度、高度和顺序，以最佳方式填充可用空间。

典型应用场景包括：导航栏、按钮组、卡片横排、表单输入组等。Flexbox 让许多过去需要 hack 才能实现的布局变得简单直接。

二、Grid：二维布局之王

CSS Grid 是二维布局系统，能同时控制行和列。当我们需要构建复杂的页面整体结构，如杂志式布局、仪表盘、产品展示网格时，Grid 是不二之选。Grid 允许我们定义网格轨道、网格区域，让元素精确地放置在指定位置。

三、何时用哪个

一个简单的原则：从内容出发选 Flexbox，从布局出发选 Grid。当元素的排列方向单一、需根据内容自适应时，用 Flexbox；当需要整体规划行列结构时，用 Grid。实际项目中，二者常配合使用--例如用 Grid 搭建页面骨架，用 Flexbox 处理局部细节。

本页面的布局就使用了 Grid：左侧主内容区与右侧 <aside> 侧边栏通过 grid 两列布局实现，响应式下自动转为单列。
