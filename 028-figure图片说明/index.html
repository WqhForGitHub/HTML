语义元素说明： <figure> / <figcaption>

<figure> 表示带说明的内容单元，可包含图片、代码、引用、视频、图表等。

<figcaption> 是其标题/说明，应作为 <figure> 的第一个或最后一个子元素。

特点：内容是"自包含"的，移到文档其他位置也不影响理解。

下方展示了多种 figure 用法。

<figure> 与 <figcaption> 演示

用语义化方式为图片、代码、引用、多媒体添加说明

1. 图片 + 说明文字

最常见的用法：一张图片配一段说明，说明与图片在语义上是一组。

2. 代码片段 + 说明

figure 不只能放图片，也可以包裹代码、图表等，figcaption 用作代码说明。

3. 引文 + 出处说明

blockquote 配合 figure/figcaption，让引用与出处形成语义组。

4. 多图组合 + 统一说明

一个 figure 内可放多张图片，共用一个 figcaption 进行整体说明。

5. 视频 + 说明

figure 同样适用于视频、音频等多媒体内容的语义化包裹。

6. 音频 + 说明

音频内容也可用 figure 包裹，figcaption 描述音频信息。

提示： <figcaption> 可以放在 <figure> 内的顶部或底部，浏览器都会正确识别其为说明文字。当一个 figure 中没有说明文字时，可以不使用 figcaption。
