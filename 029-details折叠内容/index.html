语义元素说明： <details> / <summary>

<details> 创建一个可展开/折叠的部件，用户点击可显示或隐藏额外内容。

<summary> 是其可见标题，点击它切换展开状态。

原生支持，无需 JS 即可工作。设置 open 属性则默认展开。

本页面用 details/summary 构建了一个 FAQ，并加入 JS 实现手风琴效果。

Q 1. <details> 和 <summary> 是什么？ ▼

<details> 是 HTML5 引入的交互元素，它会创建一个带展开/折叠功能的部件。 <summary> 元素作为 <details> 的第一个子元素，提供可见的标题，用户点击该标题即可切换内容的显示状态。

这对元素的最大优势是： 纯 HTML 实现，无需 JavaScript 即可工作，浏览器原生支持点击展开与折叠。

Q 2. 如何让 details 默认展开？ ▼

只需在 <details> 标签上添加 open 属性即可。例如：

<details open>

本页面的第一个问题就是默认展开的示例。注意：open 是布尔属性，存在即为真。

Q 4. 如何自定义 summary 的样式？ ▼

默认情况下， <summary> 前会有一个三角箭头标记。要隐藏它，可使用如下 CSS：

summary::-webkit-details-marker { display: none; }

隐藏后可以自定义图标，例如用 CSS 伪元素或字体图标实现自己的展开/折叠指示符。本页面的每个 summary 都隐藏了默认标记，并用自定义的箭头图标替代，展开时旋转 180 度。

另外，给 summary 添加 list-style: none; 可在 Firefox 中隐藏默认标记。

Q 5. 能否用 JavaScript 控制 details 的展开状态？ ▼

可以。通过操作 open 属性即可控制：

  • details.open = true; -- 展开
  • details.open = false; -- 折叠
  • details.toggleAttribute('open'); -- 切换状态

本页面顶部的"全部展开"和"全部折叠"按钮就是通过 JS 操作所有 details 的 open 属性实现的。同时，本页还实现了 手风琴效果 --展开一个问题时自动折叠其他问题。
