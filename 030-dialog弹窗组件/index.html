语义元素说明： <dialog>

<dialog> 是 HTML5.2 引入的原生对话框元素，无需第三方库即可实现模态弹窗。

关键 API：

dialog.show() -- 非模态显示

dialog.showModal() -- 模态显示（带遮罩）

dialog.close() -- 关闭

::backdrop 伪元素可样式化遮罩层。

关于 dialog 元素

<dialog> 是 HTML5.2 规范引入的原生对话框元素。与传统的 div + JS 模态框相比，它有诸多优势：浏览器原生管理焦点陷阱、按 Esc 键自动关闭、原生遮罩层支持、无障碍可访问性更好。

基本用法：

<dialog id="myDialog">
  <p>这是一个对话框</p>
  <button onclick="myDialog.close()">关闭</button>
</dialog>

<button onclick="myDialog.showModal()">打开</button>

遮罩层样式： 使用 ::backdrop 伪元素为模态对话框自定义背景遮罩，如 dialog::backdrop { background: rgba(0,0,0,0.5); } 。

关闭返回值： close() 方法可传入参数，关闭后通过 dialog.returnValue 获取，常用于确认弹窗判断用户选择。

提示：按 Esc 键可关闭任何打开的模态对话框（浏览器默认行为）。点击遮罩层区域也可关闭（本页通过 JS 实现）。
