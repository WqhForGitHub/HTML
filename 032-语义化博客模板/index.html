深入理解 HTML5 语义化标签

为什么我们应当告别 div 海洋，拥抱有意义的结构元素

林晓东
前端工程师 · 发表于 2026-07-08

语义化标签是 HTML5 规范中最具代表性的改进之一。它让开发者能够用具有明确含义的元素来描述页面结构，而非仅仅依赖没有语义的 div 与 span。这不仅关乎代码可读性，更影响搜索引擎优化与无障碍体验。

什么是语义化

语义化指的是用恰当的标签传达内容的含义。例如，一段导航链接应当使用 <nav> ，一篇文章应当使用 <article> ，而一个独立的、可复用的内容单元不应再被包裹在无意义的 div 中。

语义化的本质，是让机器也能像人一样理解页面的结构。 —— 某位前端布道者

常用的语义元素

在日常开发中，以下元素使用频率最高：

  • <header> ：页眉或区块头部
  • <nav> ：导航链接组
  • <main> ：页面主内容（每页唯一）
  • <article> ：独立完整的内容单元
  • <section> ：按主题分组的内容
  • <aside> ：与主内容相关的辅助内容
  • <footer> ：页脚或区块尾部

一个简单示例

下面是一段使用语义标签的代码片段：

<article>
  <header>
    <h1>文章标题</h1>
    <time datetime="2026-07-08">2026-07-08</time>
  </header>
  <section>
    <p>正文内容...</p>
  </section>
</article>

小结

语义化并不复杂，它只是一种"用对标签"的意识。当你下次写下 <div class="header"> 时，不妨停下来想一想：是不是可以直接用 <header> ？
