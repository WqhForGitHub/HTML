H5 移动端 vs PC 端 Web 开发

面试题 1 · 核心差异对比

PC 端

屏幕尺寸：大屏、横屏为主
交互方式：鼠标 + 键盘
网络环境：相对稳定 Wi-Fi
浏览器：Chrome/Edge/Safari
适配：固定宽度 + 响应式
性能：资源充裕

H5 移动端

屏幕尺寸：小屏、竖屏为主
交互方式：触摸 / 手势
网络环境：4G/5G 不稳定
浏览器：WebView / UC/QQ
适配：rem / vw 多端适配
性能：受设备限制需优化

主要区别要点

  • 布局方式：PC 多为固定居中，H5 强调流式 / 弹性 / 全屏适配
  • 注意 1px 边框、300ms 点击延迟、点击穿透等移动端特有问题
  • 触摸事件 touchstart/move/end 替代鼠标 click/hover
  • 需处理软键盘弹出、安全区域（刘海屏）、横竖屏切换
  • 资源加载：弱网下需懒加载、骨架屏、预加载优化首屏
  • 调试方式：PC 用 DevTools，H5 常用 vConsole / 真机远程调试
💡 H5 开发本质是面向移动浏览器的网页开发，核心难点在「适配 + 触摸交互 + 性能」三大方面。
