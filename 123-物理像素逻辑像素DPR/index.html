物理像素 · 逻辑像素 · DPR

面试题 2 · 像素概念解析

物理像素 (Physical Pixel)

设备屏幕上真实存在的发光点，由硬件决定，不可改变。例如 iPhone 屏幕分辨率 1170×2532。

逻辑像素 (CSS Pixel)

CSS 中使用的像素单位 px，是相对单位。浏览器在渲染时把它换算成物理像素显示。

设备像素比 DPR (Device Pixel Ratio)

物理像素与逻辑像素的比值，决定一个 CSS 像素由几个物理像素显示。

DPR = 物理像素 / 逻辑像素
1 CSS px = DPR² 个物理像素
