移动端 UI 框架

面试题 9 · Vant vs Ant Design Mobile

Vant 4

有赞出品，基于 Vue 3

生态： Vue 生态最成熟
组件： 80+ 组件丰富
体积： 支持按需引入
主题： 定制度高，CSS 变量
适合： 电商 / 业务型 Vue 项目

Ant Design Mobile

蚂蚁出品，基于 React

生态： React 生态主流
组件： 60+ 精致组件
体积： 支持按需引入
主题： 设计规范统一
适合： 金融 / 中后台 React

其他主流框架

NutUI (京东, Vue3) Varlet (Vue3, Material) Taro UI (React, 跨端) Vant Weapp (小程序) iView UI (View UI) Mint UI (已停更)
💡 选型：Vue 技术栈选 Vant / NutUI；React 选 Ant Design Mobile；多端统一考虑 Taro / uni-app。
