移动端适配方案对比

面试题 10 · rem / vw / px / 百分比
方案 原理 优点 缺点
rem 根字号随屏宽 JS 计算 兼容性好，控制简单 需 JS / 字号非整数
vw/vh 视口百分比单位原生 无需 JS，纯 CSS 兼容需 iOS8+/Android4.4+
%百分比 相对父元素 弹性好 不能用于字号，嵌套难算
flex 弹性 自动分配空间 布局自适应 不精确控字号
px + 媒体查询 多套断点写死 像素精确 维护成本高，不流畅
flexible + rem 阿里方案，已过时 历史主流 已不推荐，用 vw 替代
💡 当前最佳实践：vw + rem fallback + postcss-px-to-viewport 自动转换，无需手算。
