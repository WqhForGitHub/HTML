rem 适配方案

面试题 11 · 原理与计算

核心原理

rem = root em，相对根节点 html 字号。JS 监听屏宽动态设置 html.style.fontSize，元素尺寸用 rem，缩放即整体等比。

document.documentElement.style.fontSize = innerWidth / 设计稿宽 * 100 + 'px'

rem 值计算公式

rem = 设计稿像素 / 根字号基准(rem 与 px 比值) 例：设计稿 375 宽，基准 100 则 1rem = 100px 设计稿 200px → 200/100 = 2rem
1rem = ? px
设计稿 200px = ? rem
这个盒子 padding:0.32rem font:0.28rem
💡 通常约定 1rem = 设计稿宽 / 10，配合 px2rem 插件自动换算，开发时直接写设计稿 px。
