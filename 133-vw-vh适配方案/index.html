vw / vh 适配方案

面试题 12 · 与 rem 的区别
1vw = ? px

原理

1vw = 视口宽 1%；1vh = 视口高 1%。所有尺寸用 vw 表示即可等比缩放，纯 CSS 实现无需 JS。

设计稿 375 宽，200px 元素： 200 / 375 * 100 = 53.33vw
60vw 宽 · 4vw 字号 · 3vw 内边距
对比项 rem vw/vh
依赖 需 JS 设根字号 纯 CSS
性能 JS 阻塞 原生渲染快
兼容 极好 iOS8+/Android4.4+
横屏 按宽变化 vw 按宽；vh 按高
💡 vw 更现代，但注意横竖屏切换时 vw 按宽度变化，字号会变大；可配合 vmax/vmin 控制。
