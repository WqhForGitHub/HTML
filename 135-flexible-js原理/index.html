flexible.js 原理

面试题 14 · 阿里历史方案

原理

监听 resize/pageshow，把视口宽度除以 10，得到根字号，并给页面设置 meta viewport 缩放为 1/dpr。

function setRem() { const w = document.documentElement.clientWidth; document.documentElement.style.fontSize = w / 10 + 'px'; } setRem(); window.addEventListener('resize', setRem);

所做的两件事

1️⃣ 计算 rem 基准值（html 字号 = 屏宽 / 10）
2️⃣ 设置 viewport meta 的 scale = 1/dpr，让物理像素 1:1 还原设计稿

⚠️ 不推荐使用：flexible.js 已停止维护，因为有 viewport 缩放方案副作用大，且 vw/vh 单位兼容性已足够好。
💡 现代替代：postcss-px-to-viewport 把 px 自动转 vw，无需 JS；若需兼容低端机可引入 flexible 作 fallback。
