300ms 点击延迟

面试题 18 · 复现与解决
💡 原因：早期移动浏览器为判断"双击缩放"，在 touchend 后等 300ms 才触发 click，导致点击反应慢。

— ms响应延迟
touchend 触发
— ms响应延迟

解决方案

  • 设置 viewport width=device-width（现代浏览器遇此会自动禁用延迟）
  • 用 touchend 替代 click 并 preventDefault
  • 引入 FastClick 库
  • CSS: touch-action: manipulation（禁用双击缩放）
html { touch-action: manipulation; }
💡 现代浏览器在 viewport 含 width=device-width 时已默认消除 300ms，故多数项目无需处理。
