资源层优化

  • 合并 / 压缩 JS / CSS，开启 gzip / brotli
  • 图片用 webp / avif，按需懒加载 + 占位
  • icon 用 SVG sprite 或字体图标替代小图
  • 静态资源 CDN + 长缓存 (hash 文件名)
  • 关键资源 preload / prefetch 预取

渲染层优化

  • 骨架屏 / Loading 占位，缩短白屏感知
  • 首屏内联关键 CSS，剩余异步加载
  • 路由懒加载、组件按需引入
  • SSR / 预渲染提升首屏速度

网络与执行

  • 减少 HTTP 请求数量（HTTP/2 多路复用）
  • 接口合并、字段裁剪、防抖限流
  • Web Worker 把重计算放子线程
  • requestIdleCallback 空闲预拉取
