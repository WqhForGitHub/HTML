图片优化与 webp

面试题 21 · 移动端图片加载策略

webp 格式优势

同质量下 webp 比 jpg/png 小 25~35%，支持透明与动画；现代手机/浏览器全部支持。

✓ 体积更小 (encoding 更高效)   ✗ 兼容已 95%+

图片优化手段

✓ 选择合适格式：照片 jpg/webp，图标 svg，透明 png/webp
✓ 按设备 DPR 提供 srcset 多倍图
✓ <picture> 自动降级：webp → jpg
✓ 懒加载 loading="lazy"
✓ 占位图 / 模糊缩略图 (LQIP)
✓ CDN 动态裁剪裁剪宽度 ?w=200

picture 降级示例

<picture>
<source srcset="a.webp" type="image/webp">
<img src="a.jpg" loading="lazy">
</picture>
💡 实测：同一张图 webp 通常比 jpg 小 30%+，移动弱网下能明显提速首屏。
