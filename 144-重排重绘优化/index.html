减少重排与重绘

面试题 23 · 渲染性能优化

重排 (Reflow / Layout)

几何位置变化触发重新计算布局，开销大。改变宽高、定位、字号、窗口尺寸都会触发。

重绘 (Repaint)

仅外观变化不影响几何（颜色 / 背景等），开销小但太多也卡。

优化技巧

动画用 transform / opacity（仅合成层，不重排）
批量改样式：用 class 替代多次 style.x= 赋值
读写分离：先读完 offsetTop 再写，避免强制同步布局
使用 will-change / translateZ(0) 提升合成层
避免逐项操作 DOM，用 DocumentFragment 批量插入
频繁读 offsetWidth 再写样式 → 强制布局抖动
💡 想法：transform 走 GPU 合成层，跳过 Layout 和 Paint，移动端动画首选。
