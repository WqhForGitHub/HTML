JSBridge 原生通信

面试题 26 · H5 调原生 API

什么是 JSBridge

JSBridge 是 H5 与原生 App 之间通信的桥梁：H5 调原生能力（相机/分享/扫码），原生回调 JS。

H5 (JS)
→调用→
JSBridge
→分发→
原生 App
→回调→
H5 回调

两种通信方式

1. 注入式（推荐） ：原生向 WebView 注入全局对象

window.webkit.messageHandlers.app.postMessage({...}) // iOS window.Android.share('title', 'url') // Android

2. URL Scheme 拦截

iframe.src = 'myapp://action?name=share&cb=cb123' // 原生拦截 URL 解析参数执行，再通过 evaluateJavaScript 回调 cb123
日志区（模拟，非 WebView 下使用 mock）\n
