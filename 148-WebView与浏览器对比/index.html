WebView vs 原生浏览器

面试题 27
💡 WebView 是 App 内嵌的网页容器（基于系统 WebView 内核），相比独立浏览器有更多限制与可控性。

原生浏览器

地址栏：有
内核：系统自带最新
能力：只能 Web API
通信：无原生交互
更新：随系统
同源：严格

App WebView

地址栏：无
内核：可能被魔改 / X5
能力：可 JSBridge 调原生
通信：双向通信
更新：App 版本绑定
同源：可白名单放宽

WebView 常见坑

  • Android 4.4 以下 WebView 内核老旧，新 ES 语法不支持
  • 厂商定制内核（X5/T7/UC）行为可能与系统不一致
  • 本地 HTML / file:// 协议下 CORS / cookie 行为不同
  • iOS WKWebView 与 UIWebView 内存、稳定性差异大
  • 需配合 JSBridge 才能用相机、定位、支付等原生能力
💡 调试：Android chrome://inspect 接 USB；iOS Mac Safari → 开发 → 模拟器 / 真机。
