动画性能 CSS vs JS

面试题 28 · 优先 CSS 动画
实时 FPS：60

CSS 动画演示（transform / opacity）

使用 animation + transform，跳过 Layout/Paint，仅合成层，最流畅。

JS 动画演示（点击开/关）

JS 改 left 每帧触发重排，FPS 会明显下降。

优化原则

  • 优先 CSS transition / animation 跑合成层 (transform / opacity)
  • JS 动画用 requestAnimationFrame 替代 setTimeout
  • 避免动画改 width/height/top/left/margin
  • 加 will-change / translateZ 提升合成层
  • 大区域动画考虑 canvas / WebGL
💡 选择：UI 动效用 CSS（声明式、GPU）；逻辑复杂或物理动画用 JS + rAF；移动端慎用 JS 逐帧改布局。
