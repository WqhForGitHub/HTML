骨架屏占位

用骨架替代白屏，用户感知更快。

加载策略

  • 路由 / 组件懒加载 (import())
  • 首屏关键 CSS 内联，非关键 CSS 异步加载
  • 图片懒加载 + preload 关键图片
  • JS 拆包 + tree-shaking + 按需引入
  • 接口并行 + 字段裁剪 + 预请求

渲染与服务端

  • SSR / 预渲染 (prerender) 直出 HTML
  • CDN 就近分发 + HTTP/2 + 长缓存
  • gzip / brotli 压缩，资源精简
  • Web Vitals 监控 LCP/CLS/INP
💡 目标：LCP < 2.5s，CLS < 0.1，INP < 200ms，移动弱网下首屏白屏 < 1s。
