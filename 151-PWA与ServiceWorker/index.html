PWA 与 Service Worker

面试题 30 · 渐进式 Web 应用
浏览器能力： ServiceWorker ✓ cache ✓ fetch ✓ manifest ? installable ?

什么是 PWA

PWA (Progressive Web App)：可安装、可离线、可推送的 Web 应用，由 manifest.json + Service Worker 实现"用得像原生 App"的体验。

1. manifest.json

{ "name": "MyApp", "short_name": "App", "start_url": "/", "display": "standalone", "background_color": "#000", "theme_color": "#2563eb", "icons": [{"src":"icon.png","sizes":"192x192"}] }

HTML 引入： <link rel="manifest" href="/manifest.json">

2. 注册 Service Worker

if ('serviceWorker' in navigator) { navigator.serviceWorker.register('/sw.js') .then(reg => console.log('注册成功')) .catch(err => console.log('失败', err)); }

3. sw.js (缓存 + 离线)

const CACHE = 'v1'; self.addEventListener('install', e => { e.waitUntil(caches.open(CACHE) .then(c => c.addAll(['/','/index.html','/app.js']))); }); self.addEventListener('fetch', e => { e.respondWith( caches.match(e.request).then(r => r || fetch(e.request)) ); });
本页在 https / localhost 才能注册 SW
💡 Service Worker 是浏览器后台脚本，拦截 fetch、管理 Cache、处理 push 通知；必须在 HTTPS 环境。
