src 与 href 的区别

面试题 1 · 资源引用属性

核心区别

属性 含义 是否阻塞 典型标签
src 引入/替换当前元素的内容（Source） 会阻塞，下载完才继续解析 script / img / iframe / video
href 建立当前文档与外部资源的链接（Hypertext Reference） 不阻塞，并行下载 a / link / area

src 示例（替换元素内容）

<script src="app.js"></script> <img src="logo.png" alt="logo" /> <iframe src="page.html"></iframe>

浏览器遇到 src 会暂停 HTML 解析，下载并执行（脚本）后才继续。

href 示例（建立链接关系）

<a href="https://example.com">跳转</a> <link rel="stylesheet" href="style.css" />

link 的 href 不会阻塞解析，CSS 可并行下载；a 标签的 href 仅在点击时才请求。

记忆口诀

src = 资源进入页面（src 要下载执行）；href = 链接指向外面（href 只是地址）。

💡 script 用 src 会阻塞；link[rel=stylesheet] 用 href 不阻塞但会阻塞渲染。把 <script> 放到 body 末尾或加 defer/async 可避免阻塞。
