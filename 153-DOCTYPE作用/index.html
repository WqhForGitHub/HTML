DOCTYPE 文档类型的作用

面试题 2 · 文档类型声明

什么是 DOCTYPE

DOCTYPE = Document Type Declaration，文档类型声明，必须位于 HTML 文档第一行（<html> 之前）。

<!DOCTYPE html>

三大作用

1. 告诉浏览器以标准模式渲染（避免怪异模式 Quirks Mode）。

2. 告诉浏览器使用哪个 HTML 版本解析页面（HTML5 / XHTML / HTML4）。

3. 影响浏览器的 CSS 渲染、盒模型计算逻辑。

标准模式 vs 怪异模式

标准模式：W3C 盒模型，width = content
(写 DOCTYPE)
怪异模式：IE 盒模型，width = content+padding+border
(不写 DOCTYPE)

HTML4 vs HTML5 的 DOCTYPE

HTML4: <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN" "http://www.w3.org/TR/html4/strict.dtd"> HTML5: <!DOCTYPE html>

HTML5 简化为不区分大小写、无 DTD 引用。

💡 不写 DOCTYPE 触发怪异模式，盒模型、行高、表格布局等渲染都会改变。一定要写在第一行。
