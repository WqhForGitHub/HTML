defer 与 async 的区别

面试题 3 · script 脚本加载

三种 script 写法对比

<script src="a.js"></script> // 阻塞解析，下载执行完才继续 <script src="a.js" defer></script> // 延迟执行 <script src="a.js" async></script> // 异步执行

执行时机对比

属性下载执行顺序能否操作 DOM
无阻塞下载完立即执行（阻塞）按顺序后面 DOM 还未解析
defer并行（不阻塞）DOM 解析完成后、DOMContentLoaded 之前按书写顺序可访问完整 DOM
async并行（不阻塞）下载完立即执行（短暂阻塞）不保证顺序不确定，DOMContentLoaded 不等它
