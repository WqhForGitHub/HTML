常用 meta 标签

面试题 4 · 元信息标签

1. charset 字符编码

<meta charset="UTF-8" />

声明文档编码，避免乱码，必须放在 head 最前面。

2. viewport 移动视口

<meta name="viewport" content="width=device-width, initial-scale=1.0" />

控制移动端布局视口宽度与缩放。

3. SEO 相关

<meta name="description" content="页面描述，搜索引擎结果摘要" /> <meta name="keywords" content="关键词1,关键词2" /> <meta name="author" content="作者" /> <meta name="robots" content="index, follow" />

keywords 现在搜索引擎基本忽略，description 仍是搜索结果摘要来源。

4. http-equiv 等效 HTTP 头

<meta http-equiv="X-UA-Compatible" content="IE=edge" /> // 兼容模式 <meta http-equiv="refresh" content="3;url=https://a.com" /> // 跳转 <meta http-equiv="Content-Type" content="text/html; charset=UTF-8" />

5. 移动端 / PWA

<meta name="theme-color" content="#0f172a" /> // 主题色 <meta name="apple-mobile-web-app-capable" content="yes" /> // iOS 全屏 <meta name="format-detection" content="telephone=no" /> // 禁用电话识别

6. Open Graph 社交分享

<meta property="og:title" content="标题" /> <meta property="og:image" content="封面URL" /> <meta property="og:url" content="页面URL" /> <meta name="twitter:card" content="summary_large_image" />

用于微信/Twitter/Facebook 等分享卡片预览。

本页 head 实际包含的 meta： charset viewport description keywords author robots X-UA-Compatible theme-color og:title
💡 meta 是空元素，只有 name/http-equiv/property + content 两两配对，不显示在页面上，只给浏览器/搜索引擎读取。
