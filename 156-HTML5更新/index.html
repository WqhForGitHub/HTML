HTML5 相比 HTML 的更新

面试题 5 · 标准演进

1. 语义化标签

<header> <nav> <main> <article> <section> <aside> <footer> <time>

用语义化结构取代满屏 div，便于 SEO 和无障碍。

2. 表单增强

<input type="email/tel/url/date/range/color/number" /> <input required placeholder pattern autofocus /> <datalist> <output>

3. 多媒体

<audio src="x.mp3" controls></audio> <video src="x.mp4" controls autoplay></video>

原生音视频，不再依赖 Flash。

4. 图形

<canvas id="c"></canvas> // 位图，JS 绘制 <svg>...</svg> // 矢量图，标签直接写

5. 存储 API

localStorage.setItem(k, v) // 永久 sessionStorage.setItem(k, v) // 会话级 IndexedDB // 大型结构化存储

取代 Cookie 做本地存储。

6. 离线与连接

Application Cache（已废弃）/ Service Worker 离线缓存、WebSocket 双向通信、Geolocation 地理位置、Drag & Drop 拖放。

7. 新增 API / 标签

history.pushState postMessage Web Worker File API Web Storage Canvas 2D WebGL Fullscreen Page Visibility

8. 语法简化

DOCTYPE 从冗长 DTD 简化为 <!DOCTYPE html>；不需要写 type="text/javascript" / type="text/css"；属性可省略引号和值。

9. 废弃内容

frame/frameset/basefont/center/font/big/strike 等表现性标签移除，由 CSS 接管；引入 strict 严格模式。

💡 HTML5 = 语义化 + 原生多媒体 + 富 API + 更宽松语法；从"文档标记"转向"应用平台"。
