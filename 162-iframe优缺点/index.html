iframe 的优点与缺点

面试题 11 · 内联框架

什么是 iframe

<iframe src="https://example.com" width="600" height="400"></iframe>

在当前页面内嵌一个独立的整个文档（沙箱），拥有自己的 window/document。

优点 vs 缺点

优点
  • 嵌入第三方内容（地图/广告/视频）
  • 天然隔离 CSS、JS，互相不影响
  • 跨域资源无同源限制（src 任意）
  • 并发加载，慢页面不影响主页面
  • 实现微前端/历史沙箱
缺点
  • 阻塞父页 onload（影响性能）
  • 多文档 DOM，内存占用大
  • SEO 不受父页索引，抓不到
  • 跨域通信需 postMessage
  • 移动端缩放、滚动困难
  • 可能被劫持 / 点击劫持 (CSRF)

属性速查

src // 内嵌页地址 name // 作为 target 的名字 sandbox // 沙箱权限（allow-scripts 等） loading="lazy" // 懒加载，提升性能 referrerpolicy // 控制来源 referer allowfullscreen // 允许全屏
