label 标签的作用与使用

面试题 12 · 表单标签关联

作用

1. 扩大点击区域：点击 label 也能触发绑定的表单控件，移动端尤其友好。

2. 提升无障碍可读性：屏幕阅读器可朗读 "用户名 输入框"。

3. 提交后服务端能通过关联的 name 获取值，单选/多选语义更清晰。

方式 1：隐式（包裹）

<label>用户名：<input type="text" name="username" /></label>

方式 2：显式（for → id）

<label for="username">用户名：</label> <input id="username" type="text" name="username" />

多选 / 单选最常用

<input type="checkbox" id="agree" /> <label for="agree">同意《协议》</label>
💡 for 必须等于表单控件的 id；同 name 不同 id 才能正确分组。label 没必要包裹整个 div，纯文本+表单控件即可。
