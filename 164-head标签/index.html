head 标签的作用

面试题 13 · 文档头部

作用

head 是文档头部容器，不显示在页面上，用于存放页面的"元信息"和外部资源引用。

包含：页面标题、字符编码、SEO 信息、CSS 引用、JS 引用、预连接、图标等。

head 中常见标签

标签作用必须
title页面标题，显示在标签页/收藏/搜索结果必须
meta字符编码、viewport、SEO 等元信息charset 必须
base统一相对 URL 基准可选
link外链 CSS / favicon / manifest可选
style内联样式可选
script加载/执行 JS（优先放 body 末尾）可选
noscriptJS 禁用时显示可选

最小可用 head

<head> <meta charset="UTF-8" /> // 必不可少 <meta name="viewport" content="width=device-width, initial-scale=1" /> <title>页面标题</title> // 必不可少 </head>

真正"必不可少"的只有 title 和声明 charset 的 meta；viewport 在移动端虽非强制但强烈推荐。

head 内不应出现的内容

任何可见内容（文字、图片、div）都不应放在 head；head 内只有一个 title 可被间接显示（标签栏）。

💡 顺序建议：charset → viewport → title → meta(SEO) → link(CSS/favicon) → style → script。charset 越靠前越好（前 1024 字节内）。
