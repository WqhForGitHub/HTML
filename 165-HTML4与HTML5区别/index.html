HTML4 与 HTML5 的区别

面试题 14 · 标准演进对比

核心对比表

对比项HTML4HTML5
DOCTYPE冗长 DTD：PUBLIC "-//W3C//DTD HTML 4.01//EN" "..."<!DOCTYPE html>
字符编码<meta http-equiv="Content-Type" content="text/html; charset=UTF-8"><meta charset="UTF-8">
结构标签div + class/id 一切header/nav/main/article/section/aside/footer
多媒体依赖 Flash/插件原生 audio/video
绘图无（用 Flash/img）Canvas / SVG
表单控件text/password/checkbox/radio/submit新增 email/url/date/range/color/number 等 + 校验属性
本地存储仅 CookielocalStorage / sessionStorage / IndexedDB
离线应用无（cookie 限制大）Application Cache（已弃） / Service Worker
通信Ajax（短轮询）WebSocket / postMessage / Server-Sent Events
线程单线程Web Worker 多线程
拖放需鼠标事件模拟原生 Draggable API
地理位置需 IP 库原生 Geolocation API
语法严格（XHTML 关闭必须 /）宽松（标签可任意大小写、可省略闭合）
文档类型SGML 衍生独立标准，不再依赖 SGML

废弃标签

HTML5 移除表现性标签：frame/frameset/noframes/basefont/big/center/font/s/strike/u

这些应交给 CSS 处理，标签只承担语义。

新增 API

Canvas 2D / WebGL // 图形 Geolocation // 地理位置 Drag and Drop // 拖放 Web Storage // 本地存储 Web Worker // 后台线程 Server-Sent Events // 服务端推送 WebSocket // 全双工通信 History API // 前端路由 Fullscreen / Visibility // 全屏 / 可见性
💡 一句话总结：HTML4 是"文档标记语言"，HTML5 是"Web 应用平台"——多媒体、存储、图形、通信、线程一站式解决。
