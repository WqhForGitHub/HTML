什么是 HTML 语义化

面试题 15 · 语义化标签

定义

语义化 = 用合适的标签表达内容的含义，而不是只用 div/span 凑结构。

让机器（搜索引擎/屏幕阅读器/爬虫）和人都"看标签就知道这是什么内容"。

反例 vs 正例

❌ 不语义化 <div class="header">   <div class="title">文章标题</div> </div> <div class="content">正文</div> <div class="footer">版权</div>
✓ 语义化 <header>   <h1>文章标题</h1> </header> <article>正文</article> <footer>版权</footer>

常见语义化标签

header nav main article section aside footer h1-h6 p ul/ol/li table figure figcaption time address mark blockquote code strong/em

意义/好处

1. SEO 友好：搜索引擎更容易理解页面结构、关键词权重。

2. 无障碍：屏幕阅读器能正确朗读（导航/正文/侧栏）。

3. 可读性：团队维护时一眼看出每块是做什么的。

4. 样式解耦：结构由标签决定，样式由 CSS 决定，符合关注点分离。

5. 浏览器特性：如 table 默认列对齐，form 默认回车提交。

实践要点

① 一篇文章 1 个 h1；② 标题层级 h1→h2→h3 不要跳级；③ 列表用 ul/ol 而非 div+p；④ 引用用 blockquote、代码用 pre+code；⑤ 不为了样式而用语义标签（如用 blockquote 缩进是反语义）。

💡 语义化不是死规则，而是"标签代表含义，样式与结构分离"。结构写完不带 CSS 也能清晰可读，就是好语义。
