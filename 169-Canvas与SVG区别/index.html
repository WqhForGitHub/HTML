Canvas 与 SVG 的区别

面试题 18 · 2D 绘图方案

本质区别

Canvas：位图（栅格），用 JS 在像素上绘制，画完即固化。

SVG：矢量图（XML），标签描述图形，DOM 节点可单独操作。

对比表

对比项CanvasSVG
类型位图（基于像素）矢量（基于 XML 描述）
绘制方式JS API 实时绘制HTML 标签静态描述
是否为 DOM不是，画完无节点是，每个图形都是 DOM 节点
事件绑定只能监听 canvas 整体，需自行计算坐标可直接给每个图形绑事件
缩放放大会失真（像素）任意缩放不失真
性能元素多时仍流畅（适合数千动效）元素多时性能差（DOM 爆炸）
动画需 requestAnimationFrame 手动重绘原生 CSS / SMIL 动画
可访问性差（仅一张位图）好（标签有语义）
SEO差好，可被搜索
导出toDataURL → PNG/JPG直接保存 .svg 文件
适用场景游戏、滤镜、热力图、复杂动效图标、地图、图表、UI 图形

代码对比

Canvas: SVG: <canvas id="c" width="120" <svg width="120" height="120"> height="120"></canvas> <circle cx="60" cy="60" const ctx = c.getContext('2d'); r="40" fill="#d946ef" /> ctx.fillStyle = '#d946ef'; </svg> ctx.beginPath(); ctx.arc(60, 60, 40, 0, Math.PI*2); ctx.fill();

实时演示

Canvas（位图，画完无节点）
SVG（矢量，原生动画不失真）

选型建议

• 图形数量少、需交互、要响应式 → SVG

• 图形数量多、像素级特效、游戏 → Canvas

• 大数据可视化：折线/柱状用 SVG（百级），热力/粒子用 Canvas（千级以上）

• 3D / 复杂图形：Canvas + WebGL（Three.js / Babylon.js）

💡 一句话：SVG 像画"积木"（DOM 可控可缩放），Canvas 像画"画布"（像素绘制高性能）。ECharts 在两类元素混合时用 ZRender 自动选择。
